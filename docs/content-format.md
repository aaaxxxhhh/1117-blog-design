# slow days 고정 글 형식 — "천천히 하는 ○○" 가이드형

검색으로 찾아오고, 끝까지 읽히고, 저장·공유되도록 만든 반복 형식. 글쓰기 화면 본문 도구의 **[형식 불러오기]** 버튼으로 뼈대를 넣고 채운다.

v1.1 (2026-11-25): 같은 주제 상위 글 6건 분석 결과 반영 — 해요체 2인칭, 운영자 본인 답, 저장용 요약, 오늘 할 행동 1개.

## 1. 주제 선정 기준 (3개 중 2개 이상 충족)

| 기준 | 확인 질문 | 예 |
|---|---|---|
| 검색 의도 | 사람들이 실제로 찾는 말인가 (질문형·목록형) | 연말 회고 질문, 겨울 산책 코스 |
| 시기성 | 지금부터 4주 안에 검색이 늘어나는가 | 11월 말 → 연말 회고·결산 |
| 저장 가치 | 읽고 나서 저장·공유할 이유가 있는가 | 질문 목록, 체크리스트, 책 목록 |

## 2. 구조

| 순서 | 내용 | 분량 |
|---|---|---|
| 1) 도입 | 독자가 겪는 장면 + 이 글에서 하는 일 한 문장 | 2~3문장 |
| 2) 글 안내 | "이 글에는 ○가지가 들어 있어요" + 바로 해 볼 수 있는 방법 | 1문단 |
| 3) 본론 | `## 소제목` 2~3개, 번호 항목 3~5개, 항목마다 이유·예시 1~2문장 | 전체의 60% |
| 4) 운영자 답 | 항목 아래 `> 저의 답:` — 운영자 실제 경험만, 글 전체 3개 이하 | 1~2문장씩 |
| 5) 실천 | `## ○○를 끝까지 하는 세 가지 방법` — **굵은 팁** 3개 | 1문단씩 |
| 6) 저장용 요약 | `## 저장해 두고 쓰는 ○○` — **굵은 묶음 이름** + 항목을 한 문단에 | 2~3문단 |
| 7) 마무리 | 오늘 바로 할 행동 1개 + 공유 권유 + 다음 글 예고 | 3문장 |

## 2-1. 말투·표기 규칙

| 구분 | 규칙 | 이유 |
|---|---|---|
| 말투 | 해요체, 독자에게 말을 거는 2인칭 ("~해 보세요") | 상위 글 6건 중 다수가 대화체·2인칭 사용 (적용 사례 출처) |
| 운영자 답 | 실제 경험만 쓰기, 지어낸 예시 금지 | 직접 경험이 글의 차별점 |
| `>` 인용 | 화면 전체 폭의 큰 글씨로 표시됨 → 운영자 답 1~2문장에만 사용 | 여러 줄 목록에 쓰면 한 줄로 합쳐져 읽기 어려움 (11-25 발행 테스트에서 확인) |
| AI 결과 | 소개문·스레드 글 말투가 본문과 다르면 해요체로 고쳐 적용 | AI가 "~입니다"체로 제안하는 경우 있음 (11-25 테스트) |

## 3. 검색 노출 체크리스트

1. 한글 제목 앞쪽에 핵심 검색어 (예: "연말 회고 질문")
2. 소개문(도입 문단) 80~120자, 핵심 검색어 1회 — AI 발행 준비 결과를 기준으로 다듬기
3. 소제목 중 1개 이상에 검색어 변형 포함
4. 본문 1,500~2,500자, 번호 목록으로 항목을 구분해 훑어보기 쉽게
5. 태그 3~5개: 핵심 검색어 1 + 관련어 2~4
6. 다른 사람의 글·책 문장은 옮겨 쓰지 않고 내 말로 쓰기

## 4. 발행 순서

1. [형식 불러오기] → 본문 작성
2. [AI 발행 준비] → 소개문·분류·태그 확인 후 [적용]
3. 발행 → 발행 완료 화면에서 인스타 스토리·스레드 링크와 문구 복사해 게시
4. 3일 뒤·7일 뒤 관리자 방문 통계에서 채널별·글별 유입 확인 (utm_content = 글 번호)
